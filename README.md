# Nexzones 问题反馈

缺陷、需求、"用不明白怎么做" —— 都提在这里的 **Issues**。

> **这里取代了 Gitee 上的 `painkiller/nexzones-issues`。**
> 换过来的原因很实际:Gitee 免费版不支持附件,日志、录屏、工程文件都传不上去。
> 这边可以直接把文件拖进 issue。

## 怎么提

点 **Issues → New issue**,会自动带出模板。模板里分了几类,**只填你那一类那一块**,
其余整段删掉就行。填不了的写"不知道"也行,别留空。

三件事最省时间,填了基本就不用来回问:

| | 为什么重要 |
|---|---|
| **哪个项目**(判官 / 绯月) | 两部作品的配置和内容完全不同 |
| **国服还是国际服** | 这是**两套独立部署**,认错了会查到别处去 |
| **哪个入口**(编辑器预览 / 网页 /play / 桌面客户端 / 打包出来的包) | 同一个现象在不同入口往往是不同的原因 |

## 附件:直接拖进来

截图、录屏、`.log`、`.zip`、导出的工程文件 —— 在输入框里**直接拖拽或粘贴**即可。
这正是从 Gitee 搬过来的原因。

- 报错请贴**原文**,别只写"报错了" —— 原文里常带着文件名或错误码,照着就能定位
- 打包出来的客户端请带**版本号**,要靠它去取那一版的真实产物

## 关于旧的 Gitee 仓库

Gitee 上的历史单据保留只读,未关闭的已经搬到这里(标题里带着原单号,便于对照)。
**新问题一律提在这里**,Gitee 那边不再跟进。
